Breast cancer diagnosis with K-Nearest Neighbor

Classifying tumors as benign or malignant on the Breast Cancer Wisconsin dataset, and testing how the choice of K changes accuracy.

Type: Course project, Machine LearningTools: Python, scikit-learnData: Breast Cancer Wisconsin (Kaggle / UCI)
94.74%accuracy with K = 5
95.61%best accuracy (K = 1 and K = 3)
114test cases
5malignant cases missed at K = 5

The question

Can a simple distance-based method tell benign tumors from malignant ones using cell measurements? KNN labels a new case by the majority class among its closest known cases, which makes it easy to explain, and the dataset is entirely numeric, which suits it.

Method

  • Features are numeric cell measurements (radius, texture, area, smoothness and others), each as a mean, a standard error and a worst value. The target is the diagnosis, B or M.
  • 80% training and 20% test split, stratified so both sets keep the same share of benign and malignant cases.
  • Standardized the features using the training data only, then applied the same scaling to the test data, so no information from the test set leaks into training.
  • Fitted KNN with K = 5 as a baseline, then tried every K from 1 to 20.

Results

  • The K = 5 baseline reached 94.74% accuracy.
  • The best accuracy, 95.61%, came from K = 1 and K = 3. I recommend K = 3, because it scores the same while being less sensitive to a single neighbor.
  • The lowest accuracy, 92.98%, came from K = 16 and K = 17, so performance stays in a narrow band across K.

Reading the result

The model is accurate overall, but the 5 malignant cases it labeled benign matter most (malignant recall is 0.88). In a screening setting, a missed malignant case costs more than a false alarm, so a next step would be to tune for recall rather than accuracy alone.
