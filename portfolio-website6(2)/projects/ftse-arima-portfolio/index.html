ARIMA forecasts for an optimal FTSE All-World portfolio

Six stocks from a CAPM-optimal portfolio, each modeled with its best ARIMA, to check whether the portfolio weights still make sense.

Type: Course project, Investment and Portfolio Management (2025)Team: With Queena Diva DanielMethod: ARIMA, AICc model selection
6FTSE All-World stocks
405daily closing prices per stock
d = 1every series differenced once
20periods forecast ahead

The question

An earlier project built an optimal portfolio from FTSE All-World stocks. The CAPM version had a higher Sharpe ratio than the APT version, so it was chosen. This project asks: what do time-series forecasts say about those stocks, and do they support keeping the portfolio weights?

Method

  1. Take the six stocks of the CAPM-optimal portfolio and plot each daily price series.
  2. Test stationarity with a Box-Cox transformation check and the Augmented Dickey-Fuller test.
  3. Difference each series once, then read the ACF and PACF to propose candidate orders.
  4. Fit the candidates and keep the ARIMA with the smallest AICc.
  5. Check the residuals (Q-Q plot and a white-noise check), then forecast 20 periods ahead.

Findings

  • All six price series were non-stationary in mean and variance, so each needed first-order differencing.
  • Three of the six best models are plain differenced random walks, ARIMA(0,1,0). FRES and BARC need one extra term, and only IMB needed a richer ARIMA(4,1,2).
  • Most models left residuals that behave like white noise, which supports using them for forecasting.
  • The forecasts show prices continuing to rise for all six stocks, so the original portfolio weights were judged still reasonable.

Read with care

Limitations

  • ARIMA uses past prices only. It ignores company fundamentals and market events.
  • An ARIMA(0,1,0) carries little information beyond the last price, so an upward forecast from such a model should not be read as a strong signal.
  • The report suggests comparing ARIMA with other models, and adding a volatility model, before relying on the forecasts.
